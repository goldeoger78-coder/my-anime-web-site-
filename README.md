# 🎌 Anime Website

A simple and responsive anime website built using **HTML, CSS, and JavaScript**.  
This project is made for learning web development and improving frontend design skills.

---

## ✨ Features
- 🖥️ Clean and modern UI design  
- 📱 Fully responsive (mobile + desktop friendly)  
- 🔎 Easy navigation between sections  
- 🎨 Anime-themed layout  
- ⚡ Fast and lightweight website  

---

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript
